# SoulHauss website

The SoulHauss website. It is a preview until the "Preview" label comes off, and it is hidden from search engines until then.

Working on it with Claude: open this folder in Claude and ask for what you need in plain words. `CLAUDE.md` holds the rules for how SoulHauss looks, sounds and gets published.

- `index.html`: the words and sections
- `css/style.css`: colours, type and layout
- `js/art.js`: the drawings
- `js/main.js`: the front door, the social battery and movement
- `img/`: photos, the logo and the Cosy Club drawing
- `tools/draw_venue.py`: the script that draws the Cosy Club picture

Photos are from SoulHauss's own Instagram.
